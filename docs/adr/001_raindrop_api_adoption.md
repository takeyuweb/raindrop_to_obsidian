# ADR-001: Raindrop.io API によるブックマーク取得

## ステータス

承認済み

## 日付

2026-03-09

## コンテキスト

日々のウェブブックマークを Obsidian のデイリーノートに集約し、ナレッジベースとして活用したい。ブックマークの取得元として、プログラムからアクセス可能なサービスが必要である。

### 現状の問題点

- ブックマークがブラウザや外部サービスに分散しており、Obsidian のナレッジベースに統合されていない
- 手動でブックマークを転記するのは継続が困難

### 制約条件

- 既に Raindrop.io をブックマーク管理に使用しており、日常的にブックマークを蓄積している
- 自動化のため API でアクセスできる必要がある
- 日付指定でブックマークを取得できる必要がある

## 決定

Raindrop.io REST API v1 を使用してブックマークを取得することを決定した。

### 実装方針

1. テストトークン（有効期限なし）で認証する
2. `GET /rest/v1/raindrops/0` エンドポイントで全コレクションからブックマークを取得する
3. `search` パラメータのテキスト演算子 `created:YYYY-MM-DD` で日付フィルタリングする
4. 個別ブックマークの API（`GET /rest/v1/raindrop/{id}`）でハイライト・ノートも取得する

## 結果

### ポジティブな影響

1. **既存のワークフローを維持できる**
   - Raindrop.io での普段のブックマーク操作を変える必要がない

2. **豊富なメタデータを活用できる**
   - タイトル、URL、抜粋、タグ、コレクション、ノート、ハイライトを取得可能

3. **テストトークンにより運用が簡単**
   - 有効期限がないため、トークンリフレッシュの仕組みが不要

### ネガティブな影響・トレードオフ

1. **Raindrop.io サービスへの依存**
   - サービス終了や API 変更の影響を受ける
   - 対策: API レスポンスのデータ構造に依存する箇所を限定的にする

2. **レートリミットの制約**
   - 1分間に最大120リクエスト。ブックマーク数が多い日はハイライト取得で多数のリクエストが発生する
   - 対策: 現状の利用規模では問題なし。必要に応じてハイライト一括取得エンドポイントに切り替え可能

## 代替案

### 案1: ブラウザのブックマークエクスポート

**概要**: Chrome や Firefox のブックマークを HTML/JSON でエクスポートし、パースして取り込む

**メリット**:
- 外部サービスに依存しない
- 無料

**デメリット**:
- 手動エクスポートが必要で自動化が困難
- ハイライトやノートなどの付加情報がない
- ブラウザごとに形式が異なる

**却下理由**: 自動化が困難であり、Raindrop.io で付与しているタグ・ノート・ハイライトを活用できない

### 案2: 他のブックマークサービス（Pocket 等）への移行

**概要**: API が充実した他のブックマークサービスに移行して利用する

**メリット**:
- サービスによってはより高機能な API を提供

**デメリット**:
- 既存のブックマーク資産の移行コストが発生する
- 新しいサービスの学習コスト
- 日常のワークフローの変更が必要

**却下理由**: 既に Raindrop.io を日常的に使用しており、移行の必要性がない。Raindrop.io の API は本プロジェクトの要件を十分に満たしている
